# Domain Knowledge Catalogue

## Use and validation labels

This catalogue extracts potentially useful knowledge from Nexus 10.3.43 without adopting its implementation. Line references identify the inspected extracted source. They are review pointers, not immutable Git references. Every item must become a versioned Nexus Next domain rule only after its business owner, effective date, scope and authoritative source are confirmed.

| Validation label | Meaning |
|---|---|
| Source-observed | Present in legacy source or documentation |
| Legacy-test evidenced | A relevant legacy test was recorded as passing in B02; scope is limited to that fixture and Linux environment |
| Cross-source corroborated | More than one inspected legacy artifact expresses the same meaning |
| Requires confirmation | No accessible current approval establishes it as a Nexus Next business requirement |
