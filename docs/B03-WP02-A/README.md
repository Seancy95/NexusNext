# B03-WP02-A — Independent Investigative Capability Evaluation Design

**Status:** evaluation design produced for independent architectural and methodological review  
**Implementation:** Not Implemented  
**Benchmark execution:** Not Run  
**Hidden scenarios:** not created or stored in this repository  
**Predecessor inspected:** B03-WP01-R01 delivery `94407e66ac9b2640c1d7b05f74c613f8510eea55`

This package specifies how to answer:

> Does a bounded Nexus Next deterministic investigation produce materially better investigative findings than a competent conventional deterministic analytics solution, under equivalent evidence access and resource constraints?

An unfavourable or inconclusive Nexus result is valid. The design does not assume advantage.

## Deliverables

1. `01_EVALUATION_SPECIFICATION.md` — stages, experimental unit, fairness and judgments.
2. `02_SCENARIO_AND_GROUND_TRUTH.md` — scenario generation, protected truth and mandatory cases.
3. `03_SCORING_AND_VALUE_FRAMEWORK.md` — public rubric, numerical thresholds and statistics.
4. `04_COMPARATOR_SPECIFICATION.md` — competent baseline and independent acceptance.
5. `05_INDEPENDENCE_AND_CONTAMINATION.md` — custody, access, freeze and contamination response.
6. `06_FAILURE_ANALYSIS.md` and `failure_analysis_template.csv` — event-level failure method.
7. `07_MINIMAL_WP02_B_SCOPE.md` — smallest proposed implementation, without implementation.
8. `08_RISKS_ASSUMPTIONS_AND_DECISIONS.md` — status-labelled risks and open decisions.
9. `09_WP02_B_APPROVAL_CHECKLIST.md` — explicit approval gate.
10. `requirements_traceability.csv` — requirement-to-design mapping.

All numerical thresholds are **Proposed** and must be approved before development or hidden evaluation. All descriptions of future components are design statements. No analytical algorithm, comparator, scorer, scenario set, access-control service or benchmark infrastructure was implemented or executed.
